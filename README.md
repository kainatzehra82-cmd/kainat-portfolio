## 🚀 Featured Projects

### 💊 Medicure

**Status:** Completed  
**Technology:** Flutter • Dart • Google Gemini API • Provider • Local Storage

Medicure is an AI-powered medicine identification and health assistant application.

The application allows users to interact with an AI assistant and analyze medicine images to receive relevant medicine information. It also includes multilingual support and medication reminder functionality.

**Key Features:**
- Medicine image analysis
- AI-powered medicine assistant
- Medicine information
- Multilingual support
- Medication reminders
- Local notifications
- Local data storage
- Clean and responsive Flutter UI

**Repository:**

### 🍔 SmartBite

**Status:** 🚧 In Progress  
**Technology:** Flutter • Firebase • OpenRouter AI

The application is designed to allow customers to browse food items, view details, manage their cart, place orders, and track order status. It also includes an AI Food Assistant designed to provide food recommendations based on user preferences and requirements.

**Planned Core Features:**
- Food browsing
- Food details
- Shopping cart
- Order placement
- Order status tracking
- Restaurant menu management
- Customer order management
- AI Food Assistant
- Firebase integration
